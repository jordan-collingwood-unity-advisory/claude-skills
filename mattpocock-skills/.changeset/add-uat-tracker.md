Add `uat-tracker`, a user-invoked productivity skill for working one owner's share of a client's UAT feedback sheet. A plan session reads the sheet, takes the user's open rows (their owner code, plus unowned rows in their layer), orders them by the sheet's priority column, groups them for investigation, grills, and sets a rewind point; the next session raises one tracker issue per group (`ISSUES.md`); each later session works one group to a fix and writes its rows' status and a one-line response back. `scripts/sheet.py` is the sheet's only writer: it gives rows that have no UID the configured prefix and the next number after the largest already there (`ID_148`), lists rows with `rows`, open ones only with `--open`, adds each response newest first as `- 16 Nov, AB - text`, refuses while the file is open in Excel or when a row already links a different issue, backs the workbook up, prints every changed cell, and checks dropdowns, conditional formats and tabs survive; `--copy` runs any write on a copy first. The project describes its sheet in `docs/agents/uat-tracker.json` (format in `CONFIG-FORMAT.md`), and `new` builds an empty sheet from it, with the UID in column A, frozen, grey and locked against typing by a Custom data validation of `FALSE`, dropdowns from the config, a How to use tab and a Names tab; set up tells the user to move an existing sheet's UID column to A the same way, by hand. The config's `priorities` maps each level to what it means for the project, agreed with the user at set up from generic starting points, since a level follows how much a problem hurts the product rather than its kind; `new` writes the meanings onto the How to use tab and planning flags rows against them; `write --priority` and `--owner` set a row's priority (as a number when it is digits) and owner, refusing any value the config does not list, once the user agrees it; `add` writes rows the user agreed after the last row, dated today with their type, and gives them UIDs. Graduate leaves `task-prioritisation`, whose `scripts/graduate.py`, `## Graduate` section and `sheet` config keys are removed: raising issues from a feedback sheet now belongs to `uat-tracker`, and `task-prioritisation` keeps the team's issue table. `ask-matt` routes to `uat-tracker` for a client's testers logging feedback in a spreadsheet.
